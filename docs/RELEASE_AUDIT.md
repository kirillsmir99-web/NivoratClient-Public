## Обучение и пределы подтверждения

Тест обучения проверяет уменьшение ошибки модели и сохранение результата после перезагрузки. Дополнительно проверены пауза, продолжение, отмена с восстановлением прежних весов, недостаточные данные и отключение дальнейшего обновления.

Модель обучает профиль ручных движений камеры. Задержки последовательности оцениваются по наблюдаемым ручным действиям. Это не модель результатов серверного античита и не гарантия попадания, взрыва или совместимости с каждым сервером. Финальный игровой сценарий проверяет установку, а не все варианты детонации TNT-вагонетки.

Файл профиля называется `config/autocart_adaptive.json`. При переносе настроек со старой установленной сборки необходима миграция прежнего файла профиля и переименованных параметров; установка в основной launcher-instance в этом аудите не выполнялась. Собственный клиент появился лишь в нескольких CPU-сэмплах, чего недостаточно для точного процента нагрузки. Отсутствующие события файлового/сетевого I/O в этой записи не доказывают отсутствия этих операций.

Этот замер не является сравнением FPS до/после и не подтверждает отсутствие лагов на слабом компьютере. Для принятия релиза по производительности требуется длинный замер в загруженном мире с одинаковыми настройками, нагрузкой и аппаратурой. Применён подход поиска CPU, GC, блокировок и I/O по [официальной документации Oracle JFR](https://docs.oracle.com/en/java/javase/21/troubleshoot/troubleshoot-performance-issues-using-jfr.html).
