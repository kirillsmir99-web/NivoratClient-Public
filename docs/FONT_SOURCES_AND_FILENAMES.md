# Fonts for NivoratClient

Файлы TTF намеренно не включены в этот архив. Добавьте их вручную из официальных/open-source источников.

Ожидаемые имена:
- onest.ttf
- inter.ttf
- manrope.ttf
- rubik.ttf

Папка:
src/main/resources/assets/nivoratclient/font/

Рекомендуемые источники:
- Onest: https://github.com/google/fonts/tree/main/ofl/onest
- Inter: https://github.com/rsms/inter  (или Google Fonts mirror: https://github.com/google/fonts/tree/main/ofl/inter)
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Rubik: https://github.com/google/fonts/tree/main/ofl/rubik

После добавления сохраните OFL/LICENSE каждой семьи в licenses/fonts/.

Рекомендуемый дефолт:
Onest / Normal.

Если variable TTF вызывает проблемы в Minecraft font loader, используйте static Regular/Medium TTF той же семьи.
