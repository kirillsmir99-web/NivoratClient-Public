# Оптимизация клиента, 2026-10-01

Изменения выполнены в «Работа с GUI». Исходники Kimiko и «НОВЫЙ ПВП РЕНДЕР» не изменялись. Бэкап исходного состояния этого прохода: `backup/optimization-20261001-014857`. Релиз — PUBLIC.

## Что изменено

- Реестр публикует неизменяемый снимок только при регистрации/удалении модуля; чтение больше не копирует список. Менеджер интерфейса пересобирает категории, обёртки и поисковый список при изменении снимка, без периодического опроса. Закреплённые модули продолжают учитывать изменения закрепления.
- Поиск использует общий кешированный список и удаляет устаревшие записи через множество по идентичности. Сохраняются текущие алгоритмы поиска, названия, описания и настройки.
- MSDF: прямой доступ к распространённым глифам, ограниченный кеш ширины, ограниченный кеш псевдонимов шрифтов, сегменты геометрии вместо объекта на каждую букву, кеш поворота и границ. Кернинг, порядок вершин, градиенты и fallback сохранены.
- Кулдауны: форматирование кешируется по оставшимся тикам; время считывается один раз за проход, наличие трезубца проверяется лениво один раз за проход. Округление, сортировка и сроки сохранены.
- Диспетчер модулей кеширует сведения о переопределённых обработчиках по классу. Ошибки отдельных обработчиков записываются с ограничением частоты вместо молчаливого подавления; другие модули продолжают обрабатываться.
- AutoGG: постоянные регулярные выражения компилируются один раз; динамический шаблон имени кешируется для последнего имени. Правила распознавания событий сохранены.
- Убрана повторная инициализация звуков. Неиспользуемые наборы шрифтов исключены из JAR; зарегистрированные шрифты сохранены.
- Задержка подсказки теперь зависит от непрерывного наведения, а не от количества кадров. Раньше пауза между кадрами более 100 мс сбрасывала её.

Кеши относятся к интерфейсу и метаданным. Логику атак, выбора целей, таймингов игровых действий и отправки игровых пакетов этот проход не меняет. ClientSpoofer отдельно изменяет сетевую приватность согласно своему назначению.

## Измерения

Локальный Java-микротест после прогрева; измерены время и выделения текущего потока. Геометрия — блок из 80 глифов. Это не замер FPS всей игры.

| Повторное измерение ширины | 198,4 | 46,3 | 400 | 0 |
| Последовательный доступ к глифам | 174,8 | 36,0 | 512 | 0 |
| Геометрия без поворота | 2734,5 | 2073,1 | 7768 | 6296,1 |
| Геометрия с поворотом 25° | 4938,9 | 2480,7 | 15362,6 | 6240 |

Воспроизведение: `gradlew.bat fontBenchBefore fontBenchAfter --offline --no-daemon --no-configuration-cache --console=plain -I tools/msdf-benchmark.init.gradle`. Базовая версия берётся из указанного бэкапа. Лог: `build/optimization-benchmark-tests.log`.

JFR до/после использован для поиска горячих участков, но его выборочные веса выделений не выдаются за точное потребление RAM или прирост FPS. Файлы находятся в `build/profiles`.

## Проверки

722 JUnit-теста: существующие проверки механик и новые проверки снимков реестра, немедленного обновления категорий/поиска, форматирования кулдаунов, глифов, кернинга, геометрии, поворота и задержки подсказок при редких кадрах.

Запуск реального PUBLIC JAR в тестовом мире проверяет интерфейс, темы и редактор, поиск, RU/EN, настройки, чат, сайдбар, колесо GG и HUD. Проверяется загрузка вложенного ClientSpoofer и бренд `vanilla`; игровые проверки инвентаря подтверждают шесть типов предметов и инвалидацию после изменения слота. Для совместимости скопированы 26 сторонних JAR из указанного пользователем экземпляра; его конфиги, миры и shader packs не изменяются.

Подсказки отдельно проверены при лимите 10 FPS с этим набором модов: `build/optimization-lowfps-serial.log`, два новых снимка в `build/public-visual-smoke/captures/screenshots`. Итоговый полный проход: `build/optimization-release-final.log`. Результат полного прохода принимается только по `VISUAL_SMOKE completed` и отсутствию `VISUAL_SMOKE FAILED`, а не по одной надписи Gradle BUILD SUCCESSFUL.

В среде разработки воспроизведён плавающий `RuntimeModRemapper ClosedFileSystemException`. Ограничение `ActiveProcessorCount=1` применяется только к `publicVisualSmoke`, где оно позволило завершить ремаппинг скопированных модов. Это обход в проверочном инструменте, а не исправление исходников Fabric; обычный релизный запуск не получает этот параметр.

## Зависимость и пределы проверки

Встроен оригинальный ClientSpoofer 1.4.0 для Minecraft 1.21.11/Java 21; исходники, MIT LICENSE и SHA-256 зафиксированы в `vendor/clientspoofer`. При сборке хеш проверяется. Дополнительный отдельный JAR в mods не нужен. Альтернатива Spoofified отклонена из-за требования Java 25.

ClientSpoofer подменяет client brand и ограничивает сведения о модах в исходящих данных. Режим VANILLA может блокировать пользовательские сетевые каналы других модов. Проверка загрузки и бренда не подтверждает совместимость со всеми серверами.

Проверки выполнены на Ryzen 5 5600/GTX 1660 SUPER. Производительность на слабом компьютере и полный многопользовательский сценарий всех модулей не измерены. Сторонние моды имеют собственные предупреждения/ошибки конфигурации в тестовой среде. Поэтому обещание работы без любых ошибок или конкретного FPS на любом устройстве было бы необоснованным.

Размер, контрольная сумма установленного релиза и путь к бэкапу предыдущего установленного JAR фиксируются в `docs/native-visual-install.json`.
